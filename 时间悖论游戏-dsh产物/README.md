# 时间悖论：失控实验室 / CHRONO PARADOX: THE RUNAWAY LAB

一款以「时间回响 / 因果锚 / 同步机关」为核心机制的浏览器单机解谜游戏。使用原生 HTML、CSS、JavaScript 与 Canvas 实现，无第三方运行时依赖、无外部图片与音频素材。

> 过去的你，是现在唯一能相信的同伴。

---

## 1. 如何运行

### 推荐：本地实验终端（带审计日志落盘）

```bash
node tools/serve.mjs
```

打开 `http://127.0.0.1:4173/`。

服务器只绑定 `127.0.0.1`，提供游戏静态文件，并接收前端审计日志写入 `logs/`。

### 直接打开文件

直接双击 `index.html` 也能完整游玩。此模式下浏览器不允许网页写本地文件，开发级审计日志会退回 `localStorage` 缓存；游戏本身不受影响。

### 测试

```bash
npm test
# 或
node tests/verify-levels.mjs
node tests/engine.test.mjs
```

- `verify-levels.mjs`：用 8 关的完整动作串驱动纯逻辑引擎，证明每关可通关且行动数不超过 PAR。
- `engine.test.mjs`：覆盖回响重演、因果锚保留、因果封印、质量槽、同步锁存、撤销等底层规则。

## 2. 操作

| 操作 | 键盘 | 触屏 |
|---|---|---|
| 移动 | `WASD` / 方向键 | 虚拟方向键 |
| 等待一拍 | `Space` | 「等」键 |
| 回响 / 倒带 | `R` | 「回响」按钮 |
| 撤销一步 | `Z` | 「撤销」按钮 |
| 提示 | `H` | 目标栏「提示」 |
| 暂停 | `Esc` | 顶部暂停按钮 |
| 操作手册 | `H`（界面内）/ 顶栏 | 暂停菜单 / 标题页 |

### 核心规则

1. 每个移动、推箱、等待消耗一个时间刻度；撞墙、撞关闭的门、推不动的箱子不消耗刻度。
2. 按 `R` 倒带，把当前循环的玩家动作刻录为「回响」。下一轮里，所有回响在对应刻度同步重演。
3. 回响有实体重量：能压压力板、推箱子、占据同步节点、触发因果封印；不能拾取记忆碎片。
4. 紫铜色「因果锚箱」在倒带时保留位置。它的未来会覆盖下一轮的过去。
5. `V` 因果封印在触发器 `v` 被踩下后，本循环内永久关闭。
6. 同步节点必须同时被占据；全部成立后同步门 `G` 永久开启。方形质量槽只接受箱子。
7. 每关结算三颗星：完成、回收记忆碎片、总行动刻度 ≤ PAR。

## 3. 八个实验区

| 扇区 | 名称 | 引入机制 |
|---|---|---|
| 01 | 校准室 | 回响、压力板 A |
| 02 | 回声井 | 双回响、等待、A/B 双门 |
| 03 | 动量舱 | 回响替身 + 推箱 |
| 04 | 静默间 | 因果锚、单向因果封印 |
| 05 | 镜像廊 | 回响与因果锚接力 |
| 06 | 共振环 | 三点同步节点 |
| 07 | 歧路庭 | 质量槽、双因果来源、封印 |
| 08 | 核心室 | 五节点核心同步、完整因果闭环 |

每关包含一条 ARIADNE 情境文本、三条递进提示与一枚可选记忆碎片。八枚碎片拼出 ARIADNE 与事故的完整真相；终局提供两个不可逆结局。

## 4. 技术结构

```text
index.html                  页面结构、屏幕、对话与可访问性语义
css/style.css               视觉系统、响应式布局、动效与 reduced-motion
js/engine.js                纯逻辑因果引擎（可在 Node 中独立测试）
js/levels.js                八关地图、叙事、提示与参数
js/renderer.js              Canvas 棋盘、标题观测窗、结局背景、环境粒子
js/game.js                  应用控制器、屏幕流、输入、存档、审计日志接入
js/audio.js                 WebAudio 程序化音景与音效
js/logger.js                开发级前端审计日志、TraceID 与批量上报
tools/serve.mjs             静态服务器 + /api/logs/report 落盘接口
tests/                      关卡可解性与底层规则测试
logs/                       运行时生成（.gitignore 已忽略）
```

### 引擎设计

- 规则全部在 `engine.js` 的 `ChronoGame` 中；渲染层只读取状态，不复制规则。
- 回合按时间刻度推进；玩家动作前先结算所有回响的重演，保证确定性。
- 玩家动作被阻挡时，整个刻度会回滚，不会让回响“偷跑”。
- 因果锚在倒带时保留；普通箱子与玩家、压力板、门、封印、同步锁存全部重置。
- 撤销使用完整快照，撤销动作不会返还已消耗的回响次数。
- 所有关卡均有可执行动作串与自动化回归。

### 视觉与音效

- 所有图形由 Canvas 2D 程序化绘制：仪器铭牌、石墨地块、压力板、能量门、回响重影、因果锚、传送门、时间核心。
- 因果链：压力板被压住时，会画出通往对应门的流动因果线；同步节点同时生成向核心门的连线。
- 回响拥有青玉色重影、编号、记录路径与轻微 RGB 裂相；因果锚拥有紫铜色时间环与保留位置。
- 音效由 WebAudio 即时合成：低频实验室底噪、机械按键、压力板钟琴、封印噪声、同步和弦、倒带反向噪声与结局音景。
- 支持系统级 / 手动「减少动态效果」：停止粒子、扫光、屏幕震动和长倒带动画，但保留状态变化。

### 响应式与无障碍

- 桌面三栏仪器布局；手机单列布局，含紧凑因果监控与拇指区方向键。
- 键盘全流程可操作；`dialog` 原生焦点陷阱；可见 `:focus-visible`。
- 关键机制全部有文字/形状/颜色三重编码（门字母、节点数字与方圆形态、锚箱文字）。
- `aria-live` 播报位置、回响数、门状态与余响能量；减少动效为硬性可访问性选项。
- 触屏主控制目标 44px；移动端适配 390×844。

## 5. 审计日志 / TraceID

本项目按开发级审计日志规范，为每个玩家操作构建完整链路：

```text
[请求到达] → [中间件/输入闸门] → [参数/规则校验] → [业务执行]
           → [状态变化] → [数据层修改] → [响应返回]
           → [异常]（如发生）
```

同一次操作链路始终使用同一个 `traceId`。被界面闸门、暂停、倒带锁、引擎规则拒绝的请求也会落盘，并记录拒绝层、原因、状态码和业务影响。

运行 `node tools/serve.mjs` 后：

- 日志目录：`logs/`
- `frontend-dev-YYYY-MM-DD.log`：前端上报的结构化 JSON（每行一条）
- `audit-dev-YYYY-MM-DD.log`：便于非技术人员阅读的白话链路日志
- `server-dev-YYYY-MM-DD.log`：HTTP 请求到达、参数校验、拒绝、响应与耗时
- `error-YYYY-MM-DD.log`：服务端异常
- 前端上报接口：`POST /api/logs/report`；健康检查：`GET /api/logs/health`

适用层级：前端输入/UI、界面中间件、因果引擎业务层、localStorage 数据层、外部日志接口、服务端接收与落盘。登录、权限、数据库 SQL 等层级在本离线单机游戏中不适用，未虚构。

日志中不会记录密码、Token、私钥、手机号等敏感信息；本项目也不收集此类数据。

### 手动检查日志

```bash
# 查找一次具体操作链路
Select-String -Path logs/audit-dev-*.log -Pattern "traceId=rewind-"

# 查看前端结构化事件
Get-Content logs/frontend-dev-*.log -Tail 20
```

> 链接 `http://127.0.0.1:4173/` 时前端日志会落盘。直接用 `file://` 打开时，浏览器不允许写文件，日志会自动缓存在 `localStorage` 的 `chrono.audit.spool.v1` 中，游戏不受影响。

## 6. 存档

- 保存在浏览器 `localStorage` 的 `chrono.progress.v1` 中。
- 存储已稳定扇区、最佳行动数、星级、记忆碎片、已见结局、当前扇区与可访问性设置。
- 设置中可重置全部实验记录；关闭游戏不会丢失已完成进度。
- 无服务器端账户、无网络同步。

## 8. 浏览器支持

使用原生 Canvas 2D、WebAudio、`dialog`、CSS Grid、CSS 自定义属性与 `ResizeObserver`。建议使用当前版本的 Chrome、Edge、Firefox 或 Safari。旧版浏览器缺少的部分增强能力会静默降级，核心玩法不依赖网络。
