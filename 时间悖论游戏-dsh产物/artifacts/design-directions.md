# Design Divergence / 早期方向比较

本文件记录在实现前对四个结构性方向的比较。结论不是“微调颜色”，而是不同的观看与操作模型。

## A. 仪器化观察窗（CHOsen）

- 主体：一个被观测的因果实验舱 + 环绕它的仪控台。
- 阅读顺序：标题/叙事 → 因果核心 → 任务与操作。
- 材料：石墨、青玉磷光、紫铜因果锚、蚀刻铭牌。
- 交互：玩家像操作实验终端一样移动、倒带、读取回响，而不是“点击卡片”。

**选择理由**：最直接对应“时间回响 + 因果锚 + 同步节点”的机制；可以把 HUD 变成真实仪器而不是装饰；桌面与移动端均可重排为“舞台 + 仪表 + 控制”。

## B. 纸质事故档案（REJECTED）

- 主体：卷宗、封印胶带、事故报告、打字机。
- 问题：更像叙事调查游戏，无法自然承载实时机关、回响路径和关卡状态；使玩法退居叙事之后。

## C. 钟表机械剧场（REJECTED）

- 主体：巨大齿轮、黄铜轨道、舞台布景。
- 问题：齿轮会成为视觉噪音，遮挡棋盘状态；会让玩家误以为有复杂物理系统而实际没有。

## D. 霓虹控制室（REJECTED）

- 主体：紫蓝霓虹、玻璃面板、发光卡片。
- 问题：通用 AI/赛博模板，无法与“实验仪器”“因果读数”“时间锚”的具体题材建立关系。

---

## 被借鉴的视觉关系

- 科学仪器面板：局部细线、刻度、序号、读数、单一主视觉对象。
- 钟表/时间装置：同心环、轨道、指针式因果读数。
- 档案馆：档案编号、事故记录、逐层解锁的记忆碎片。
- 游戏可读性：机关用“字母 + 形状 + 颜色”三重编码；状态不只靠氛围。

## 被拒绝的默认模式

- 居中的巨大标题 + 两枚按钮 + 三条功能卡片。
- 玻璃拟态卡片墙、紫蓝渐变背景、发光胶囊按钮堆叠。
- 无终局的“概念展示”页面；没有可完成的游戏循环。
