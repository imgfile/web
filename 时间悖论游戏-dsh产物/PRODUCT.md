# PRODUCT

## 产品

《时间悖论：失控实验室》 — 一款可直接在浏览器中运行的单人时间循环解谜游戏。

## 玩家与场景

- 玩家：喜欢《Braid》《Outer Wilds》《Patrick's Parabox》《Baba Is You》等作品，享受在确定性规则中寻找“原来还能这样”的玩家；桌面端为主，移动端可玩。
- 场景：10–30 分钟一次完整流程；8 个递进式实验区，可中断、可重开、可回访关卡。
- 核心工作：观察因果结构，规划行动，用“回响”把过去的自己变成可协作的物理实体；在有限回响次数内抵达传送门，并尽量回收记忆碎片。

## 核心句

过去的你，是现在唯一能相信的同伴。

## 不可替代的对象

一个实时可见的因果实验室：玩家操控的路线、回响幽灵、紫铜色因果锚、压力板与能量门共同构成一个可被读取的状态机。界面不是包装，而是这台机器的仪表面板。

## 内容真实性

- 所有关卡、叙事、美术与音效均为本项目原创生成，无外部素材依赖。
- 游戏逻辑与关卡可解性由 Node 测试验证。
- 内容等级：L3，作者型叙事与体验。

## 硬约束

- 双击 `index.html` 即可进入游戏；核心玩法离线可运行。
- 无第三方运行时库；不依赖字体 CDN、图片 CDN 或网络接口。
- 键盘与触屏都可完整操作；提供减少动态效果模式。
- 全量前端审计日志可上报到本地 `tools/serve.mjs` 写入 `logs/`，离线时静默缓存。
- 不出现骗点击的假按钮、不可完成的关卡、以重复换皮填充的关卡。

## 成功标准

- 机制递进清晰：移动/推箱 → 回响 → 因果锚 → 因果封印 → 同步节点 → 综合。
- 至少 8 个互相区分、可验证的关卡；一个完整开场、结局与关卡选择流程。
- 首屏与游戏画面在 1440×900 与 390×844 下均有明确的视觉主体与可操作性。
- 浏览器控制台无错误；存档、重开、暂停、帮助、静音、减少动态效果均可恢复。
