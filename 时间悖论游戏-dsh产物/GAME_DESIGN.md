# GAME DESIGN — 时间悖论：失控实验室

## 1. 世界与叙事

俄耳甫斯深井实验室（ORPHEUS-9）在一场因果引擎校准事故后陷入 17 分钟的时间闭环。玩家是唯一保留记忆的“锚定观测者”，在实验室人工智能 ARIADNE 的引导下穿过九个失稳区（序章校准室 + 八个实验区），抵达核心室。

每一关的出口是一道传送门。玩家会在关卡中拾取可选的“记忆碎片”，拼出事故真相：Ariadne 在事故后违法启动因果引擎，试图从已发生的事故中救回两个人；玩家是第 4097 次循环里的“你”。终局提供两个不可逆的选择，并给出两个不同的尾声。

## 2. 核心规则

### 回合与动作

- 网格移动，一步一个时间刻度。方向键 / WASD / 触屏方向键移动；空格等待；Z 撤销一步。
- 推动箱子消耗一个刻度；推不动、撞墙、撞关闭的门不消耗刻度。
- 抵达出口传送门即完成关卡。

### 回响（ECHO）

- 按 R（或“回响”按钮）将当前循环彻底倒带。
- 当前循环中玩家成功执行的每个动作（移动、推箱、等待、触发机关）会被刻录为一个新的回响。
- 新循环开始时，所有既有回响与你同步重演各自记录的动作：第 N 个玩家动作发生时，所有回响执行各自的第 N 个记录动作。
- 回响有实体重量：可压住压力板、推动箱子、触发封印机关，但不能拾取记忆碎片。玩家可以穿过回响。
- 每次回响消耗一枚余响能量。关卡限定可回响次数；每一轮只能新增一个回响。
- 达到回响上限后仍可继续行动；但无法再次倒带。通常需要在最后一轮直接通关。

### 因果锚（ANCHOR CRATE）

- 紫色“因果锚箱”在倒带时不会回到初始位置，而是保留倒带前的最终位置。
- 因果锚可以选择在任何时刻倒带；它的未来会覆盖它的过去。
- 因果锚同样可以压住压力板、同步节点，参与推箱与阻挡。

### 机关

- A 系压力板 / 门：任意实体站在压力板上时，同编号的门打开。
- B 系：同 A，用于并行逻辑。
- 因果封印 V：初始开启。任意实体踏上封印触发器 v 后，V 在本循环剩余时间内永久关闭。
- 同步节点 1–4：同一循环中全部同步节点同时被实体占据时，同步门 G 永久打开（本循环内）。
- 记忆碎片 *：仅玩家可拾取；倒带后重置。在本轮通关前拾取才计入评价。

### 评价

- ★ 完成关卡。
- ★ 在通关轮拾取记忆碎片。
- ★ 总行动刻度 ≤ 关卡标准（PAR）；重开/撤销不影响。

## 3. 九区结构

| # | 区域 | 教学/变化 | 计划机制 |
|---|---|---|---|
| 1 | 校准室 | 回响基础：留下自己压板 | 单回响，压力板 A |
| 2 | 回声井 | 多重回响：两个自己 | 双回响，A + B 门 |
| 3 | 动量舱 | 回响与推箱 | 回响压板 + 推普通箱 |
| 4 | 静默间 | 因果锚与单向封印 | 因果锚保留 + 被封印困住 |
| 5 | 镜像廊 | 因果锚 + 回响协作 | 双系统组合 |
| 6 | 共振环 | 同步节点 | 玩家 + 双回响三点同步 |
| 7 | 歧路庭 | 多因果源叠加 | 锚 + 双回响 + 推箱 + 封印 |
| 8 | 核心室 | 终极同步 | 玩家 + 双回响 + 因果锚四点同步 |

## 4. 操作

- 移动：方向键 / WASD / 虚拟方向键
- 等待：Space
- 回响：R
- 撤销：Z
- 重置关卡：Backspace（确认）
- 帮助 / 手册：H 或按钮
- 暂停：Esc
- 音效：M / 设置
- 减少动态效果：设置内；默认跟随系统

## 5. 视觉方向

“实验室里的精密仪器，而不是霓虹赛博模板。”

- 深墨黑石墨台面、骨白文字、青玉色回响、紫铜色因果锚、琥珀色 A 系机关。
- 主舞台是一块被加工过的因果观测窗；左右是细窄的仪器轨道，不做等宽卡片墙。
- 字体层级：大标题用 Bahnschrift / 微软雅黑粗体；仪表标签用 Cascadia Mono / Consolas；正文用 Segoe UI / 微软雅黑。
- 签名动效：倒带时所有实体沿轨迹后退、RGB 裂相等离子残影，随后回响从轨迹尽头显影。
- 声音：低频实验室嗡鸣、机械触键、压力板钟琴、倒带反向噪声、同步和弦。
- 减少动态效果：取消粒子、震屏、扫光与裂相，保留即时状态变化。
