# 时间悖论：失控实验室

> 每一次回溯，都会留下一个你。

一款可直接在浏览器中运行的原创时间操控 / 因果解谜游戏。项目没有外部依赖、没有占位素材、没有构建步骤。

## 启动

直接打开 `index.html`，或在目录中启动任意静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

## 操作

| 输入 | 行为 |
| --- | --- |
| `WASD` / 方向键 | 移动一格 |
| `E` | 与脚下的终端交互 |
| `Space` | 等待一个时间刻度 |
| `R` | 固化当前时间线为回声，并重新开始 |
| `Backspace` / `⌫` | 重写当前时间线（保留已固化回声） |
| `X` | 打开清空本层缓存的确认框 |
| `U` | 回收最后一条回声 |
| `H` / `?` | 打开操作与机制手册 |
| `Esc` | 暂停 |
| `M` | 静音 / 开启声音 |

也可点击相邻地格移动、点击脚下终端交互，或使用移动端触控面板。

## 核心机制

- **因果刻度**：只有成功的移动、等待与交互会推进 `CHRONON`。回声与当前角色在每个刻度同步行动。
- **时间回声**：按 `R` 把本次路径封装为一条回声。回声会从起点重走原路径，然后在终点保持位置；它能够持续压住压力板，也会受到门体阻挡。
- **因果对象**：已固化时间线写入的终端会保持开启状态；未固化的当前路径仍可被重写。
- **记忆终端 `M`**：拒绝实体签名，只接受回声写入。你需要在路径中记录交互，再让回声完成实际写入。
- **共振板 `R`**：需要两个实体同时占用，可以由两个回声或“你 + 回声”共同满足。
- **闭锁门 `z`**：当所有条件在某个刻度同时成立后永久保持开启。最终舱的解谜要求你利用这一点，先让门记住条件，再离开锚点。
- **因果门**：门字符与压力板 / 终端条件相连，界面中的条件列表会实时显示当前状态。

## 七个实验舱

七个舱室以递进方式引入机制：

1. 线性校准：移动、等待、终端与门。
2. 第一道回声：回声保持压力板。
3. 双生锚点：两条时间线、同步条件。
4. 因果级联：一条回声为另一条回声开门。
5. 记忆残响：记忆签名与持久因果。
6. 共振腔室：三回声堆栈与共振板双见证。
7. 悖论核心：闭锁条件与全机制综合。

每层都有三条渐进线索，可在不离开游戏的情况下获取；也不会直接替玩家完成解谜。支持逐层解锁、章节回访、最佳评价与本地进度保存。

## 技术与设计

- 纯 `HTML + CSS + JavaScript`，零运行时依赖。
- 关卡以字符地图数据声明，编译为墙、地板、门、压力板、终端、出口与回声栈的状态机。
- 行动结算使用固定刻度 + 同步回放：门开启快照在同一刻度内固定，回声随后按记录动作推进，避免“谁先按谁生效”的含糊规则。
- 视觉渲染使用 Canvas 2D：程序化正交实验舱、地形网格、门体滑开、压力板脉冲、终端全息、回声残影与粒子系统。
- 声音由 Web Audio API 程序化合成，包括环境低鸣、门体机械声、终端写入、时间分裂与完成和弦；支持静音。
- 进度、最佳评价和声音设置保存在 `localStorage`，在不可用环境下会自动降级。
- 响应式布局覆盖桌面、平板和手机；提供触控方向键、操作按钮、键盘焦点管理和 `prefers-reduced-motion` 降级。
- 开发辅助：控制台只读诊断接口 `window.__CHRONO_LAB__.getState()`。

## 文件

- `styles.css`：视觉系统、布局、响应式与动效。
- `game.js`：关卡数据、模拟器、UI 状态、Canvas 渲染、音频和存档。
